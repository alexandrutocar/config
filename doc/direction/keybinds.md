# Key-Binds

## System & Session

| Shortcut                     | Function                                                   |
|------------------------------|------------------------------------------------------------|
| Super + Shift + E            | Exit River (via uwsm stop)                                 |
| Super + Q                    | Close the focused window                                   |
| Super + S                    | Lock the screen                                            |
| Super + F11                  | Enter Passthrough Mode (disables all other river bindings) |
| Super + F11 (in Passthrough) | Return to Normal Mode                                      |

## Application & Utilities

| Shortcut               | Function                         |
|------------------------|----------------------------------|
| Super + Shift + Return | Open terminal (foot)             |
| Super + A              | Open application launcher (tofi) |
| Super + Shift + S      | Take a screenshot                |

## Window Navigation & Layout

| Shortcut          | Function                                         |
|-------------------|--------------------------------------------------|
| Super + J         | Focus next window in stack                       |
| Super + K         | Focus previous window in stack                   |
| Super + Shift + J | Swap focused window with next                    |
| Super + Shift + K | Swap focused window with previous                |
| Super + Return    | Zoom: Move focused window to the master position |
| Super + H         | Decrease main area ratio (shrink master)         |
| Super + L         | Increase main area ratio (grow master)           |
| Super + Shift + H | Increase number of windows in main area          |
| Super + Shift + L | Decrease number of windows in main area          |
| Super + Space     | Toggle Floating mode for window                  |
| Super + F         | Toggle Fullscreen                                |

## Manual Window Manipulation

| Shortcut                             | Function                              |
|--------------------------------------|---------------------------------------|
| Super + Alt + {H, J, K, L}           | Move window (Left, Down, Up, Right)   |
| Super + Alt + Shift + {H, J, K, L}   | Resize window (Left, Down, Up, Right) |
| Super + Alt + Control + {H, J, K, L} | Snap window to screen edge            |

## Monitor & Orientation

| Shortcut                        | Function                                             |
|---------------------------------|------------------------------------------------------|
| Super + Period (.)              | Focus next monitor                                   |
| Super + Comma (,)               | Focus previous monitor                               |
| Super + Shift + Period          | Send window to next monitor                          |
| Super + Shift + Comma           | Send window to previous monitor                      |
| Super + {Up, Right, Down, Left} | Change layout orientation (Top, Right, Bottom, Left) |

## Tags (Workspaces)

| Shortcut                        | Function                                |
|---------------------------------|-----------------------------------------|
| Super + [1-9]                   | View tag (Workspace) 1-9                |
| Super + Shift + [1-9]           | Move focused window to tag 1-9          |
| Super + Control + [1-9]         | Toggle view of tag 1-9 (Multi-tag view) |
| Super + Shift + Control + [1-9] | Toggle tag 1-9 for focused window       |
| Super + 0                       | View all tags simultaneously            |
| Super + Shift + 0               | Apply all tags to focused window        |

## Media & Hardware (Works even when locked)

| Shortcut              | Function                   |
|-----------------------|----------------------------|
| XF86AudioRaiseVolume  | Increase Volume            |
| XF86AudioLowerVolume  | Decrease Volume            |
| XF86AudioMute         | Mute/Unmute Audio          |
| XF86AudioPlay / Media | Play/Pause media           |
| XF86AudioNext / Prev  | Next/Previous track        |
| XF86MonBrightnessUp   | Increase Screen Brightness |
| XF86MonBrightnessDown | Decrease Screen Brightness |
| XF86AudioMicMute      | Mute Microphone            |
| XF86WebCam            | Toggle Webcam              |

## Mouse Bindings

| Shortcut                 | Function             |
|--------------------------|----------------------|
| Super + Left Click       | Move window          |
| Super + Alt + Left Click | Resize window        |
| Super + Middle Click     | Toggle floating mode |
